# Archive

Frozen. Describes surfaces that may no longer exist. Not authoritative for any
current question.

Everything here was live once. It is kept because archiving is reversible and
costs nothing, not because it is still true. Being in this directory *is* the
supersession notice — there are no per-file warning banners, and there is no
index.

Documents here may name a pre-rebrand product ("Zenote"), features that were
later removed, plans marked "Ready to Implement" that shipped years of commits
ago, and status tables frozen at the day they were written.

**This directory is excluded from default search** by the repo-root `.ignore`.
To search it deliberately:

```sh
rg --no-ignore 'pattern' docs/archive/
```

For what is true now, see `CLAUDE.md` and the routing table in it.
